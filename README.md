# Apontamento de Horas V1.8 — até 2 parceiros

Esta versão mantém o fluxo BHAP1 da V1.7 e acrescenta **Parceiro 1** e **Parceiro 2** em cada apontamento.

- Os dois parceiros são opcionais.
- O pacote BHAP1 passa os parceiros separadamente para o Banco de Horas V4.5.
- Mantém o campo legado `companhia` no pacote para compatibilidade.
- Registros antigos salvos no aparelho continuam funcionando.
- O envio pelo WhatsApp continua levando somente o código `BHAP1:...`.

No Banco de Horas V4.5, os parceiros são associados aos funcionários e cada integrante recebe seu próprio lançamento com as mesmas horas.
